# Školní projekty – PHP a databáze

Cvičení z PHP a MySQL (předmět DBA).

| Složka / soubor | Obsah |
|---|---|
| `hotely/` | Databáze rekreačních objektů (1000 hotelů a penzionů). Umí filtrovat, vkládat, opravovat a mazat záznamy (CRUD). |
| `PRACE II/` | Samostatná práce: kniha návštěv a práce s databází (vkládání, zobrazení, vyhledání, seskupení, mazání). |
| `web/` | Web o čajích (zelený, černý, bílý, žlutý, oolong) se společnou hlavičkou a patičkou přes `include`. |
| `kniha.php`, `kniha_script.php` | Kniha návštěv, která ukládá záznamy do souboru. |
| `form.php`, `maturita_z.php`, `formA.txt` | Formuláře a zpracování odeslaných dat. |
| `pole.php`, `cykli.php`, `vetveni.php`, `funkce.php`, `regular.php` … | Základy PHP: pole, cykly, větvení, funkce a regulární výrazy. |
| `soubory.php` | Práce se soubory. |

## Spuštění

Stačí lokální server s PHP a MySQL, například [XAMPP](https://www.apachefriends.org/). Složku zkopíruj do `htdocs` a otevři `http://localhost/...`.
Připojení k databázi je nastavené na lokální XAMPP (`localhost`, uživatel `root`, bez hesla).
